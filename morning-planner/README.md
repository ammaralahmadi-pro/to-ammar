# Morning Planner (MVP)

تطبيق Expo / React Native يحسب وقت الاستيقاظ: `الوصول − القيادة − التجهيز` (+15 د عند الزحمة الشديدة). يعمل بدون إنترنت.

```bash
npm install
npm start      # ثم افتحه بـ Expo Go
npm test       # اختبارات الحساب
```

- `src/lib/calc.ts` منطق الحساب · `storage.ts` AsyncStorage · `notifications.ts` الإشعارات المحلية الأسبوعية
- حتى 3 جداول، أيام مخصصة، إشعار ليلي (قبل النوم بساعة) وإشعار مغادرة، قابلة للتعطيل.

**قيود MVP:** الرنات الخمس محفوظة كإعداد لكن الصوت الفعلي هو الافتراضي حتى تُضاف ملفات صوتية؛ على iOS الإشعارات المحلية ليست منبهاً حقيقياً (تُضاف لاحقاً بوحدة أصلية). لم يُختبر على جهاز.
