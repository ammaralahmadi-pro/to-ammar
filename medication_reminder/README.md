# تذكير الأدوية (Medication Reminder) — MVP

تطبيق جوال (Flutter) يساعد المستخدم على الالتزام بجدول علاجه: يسجّل بيانات كل دواء
حسب وصفة الطبيب، ويضبط تنبيهات محلية تلقائية بمواعيد الجرعات حتى انتهاء مدة العلاج —
تعمل حتى لو كان التطبيق مغلقًا تمامًا.

## لماذا Flutter وليس تطبيق ويب؟

إشعارات المتصفح لا تعمل بشكل موثوق بعد إغلاق الصفحة. هذا التطبيق يستخدم
`flutter_local_notifications` لجدولة إشعارات حقيقية على مستوى نظام التشغيل
(Android/iOS)، تصل في وقتها حتى لو كان التطبيق مغلقًا، مع أزرار إجراء مباشرة
داخل الإشعار: **"تم أخذها"** و**"تأجيل 10 دقائق"**.

## نطاق هذه النسخة (MVP)

- إضافة / تعديل / حذف دواء (الاسم، الجرعة، الكمية المتوفرة، عدد المرات باليوم،
  أوقات الجرعات (يدويًا أو توزيع تلقائي متساوٍ)، عدد أيام العلاج، تاريخ البدء، ملاحظات).
- جدولة تلقائية لكل الجرعات (عدد المرات × عدد الأيام) فور إضافة الدواء.
- إشعار محلي مجدول لكل جرعة يحتوي اسم الدواء والجرعة، بزرَّي "تم أخذها" و"تأجيل 10 دقائق".
- تعليم الجرعة كـ"مأخوذة" من داخل الإشعار (حتى والتطبيق مغلق) أو من داخل التطبيق.
- توقف تلقائي للتذكيرات بعد انتهاء عدد أيام العلاج (لا تُجدوَل جرعات بعد تاريخ الانتهاء).
- شاشة تفاصيل الدواء بجدول كامل للجرعات (مأخوذة / غير مأخوذة) مع نسبة التزام تقريبية.

خارج نطاق هذه الجلسة (المرحلة الثانية): تنبيه نفاد الكمية، تنبيه تجديد الوصفة،
دعم عدة مستخدمين، تصدير PDF.

## البنية

```
lib/
  models/            Medication, Dose
  services/
    database_service.dart      تخزين محلي عبر sqflite
    notification_service.dart  جدولة وإدارة الإشعارات المحلية (flutter_local_notifications)
  providers/
    medication_provider.dart   منطق الأعمال: بناء جدول الجرعات، ربط DB بالإشعارات، الحالة
  screens/           الشاشة الرئيسية، إضافة/تعديل دواء، تفاصيل الدواء
  widgets/           عناصر واجهة قابلة لإعادة الاستخدام
  utils/             توزيع أوقات الجرعات تلقائيًا
```

## التشغيل محليًا

هذا المجلد يحتوي كود Dart/Flutter فقط (بدون سقالة `android/` و`ios/` الأصلية،
لأنها تُنشأ آليًا). للتشغيل:

```bash
cd medication_reminder
flutter create .        # يولّد مجلدي android/ و ios/ دون المساس بمجلد lib/
flutter pub get
```

بعد ذلك أضف الأذونات والـ receivers الموجودة في `android_manifest_snippet.xml`
إلى `android/app/src/main/AndroidManifest.xml` (مطلوبة لعمل الإشعارات المجدولة
بدقة، ولإعادة جدولتها تلقائيًا بعد إعادة تشغيل الجهاز).

كذلك، في `android/app/build.gradle` تأكد أن `minSdkVersion` لا يقل عن 21،
وفعّل `coreLibraryDesugaring` إن طلبه `flutter_local_notifications` عند البناء
(ستظهر رسالة واضحة من أداة البناء إن كان مطلوبًا).

ثم شغّل التطبيق:

```bash
flutter run
```

## ملاحظات تقنية

- **الجدولة**: عند إضافة دواء، يُحسب عدد الجرعات = عدد المرات باليوم × عدد الأيام،
  وتُجدوَل لكل جرعة إشعار منفصل عبر `zonedSchedule` باستخدام حزمة `timezone`.
- **التعديل**: تعديل دواء يُلغي كل الإشعارات المعلّقة القديمة له ويعيد بناء الجدول
  من جديد، لتفادي تعارض الجرعات القديمة مع الجديدة.
- **العمل والتطبيق مغلق**: زر "تم أخذها" في الإشعار يُعالَج عبر
  `onDidReceiveBackgroundNotificationResponse` (isolate خلفي منفصل) ويكتب مباشرة
  في قاعدة بيانات SQLite المحلية دون الحاجة لفتح التطبيق.
- **قاعدة البيانات**: sqflite (SQLite) محليًا بالكامل — لا حاجة لخادم أو اتصال إنترنت.
- **أندرويد 12+**: يتطلب إذن "الجدولة الدقيقة" (Exact Alarms)، والتطبيق يطلبه تلقائيًا
  عند أول تشغيل.
